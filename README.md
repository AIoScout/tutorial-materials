# AIoScout Tutorial Materials

Teaching materials for the AIoScout Physical AI & Autonomous Robotics curriculum, adapted from HKUST ISDN 2602 laboratory material (2025) for secondary school students.

## Contents

- `index.html` — curriculum overview (four parts: Move, Sense, Connect, Think), with links to each lab
- `slides/` — classroom slide decks (single-file HTML, arrow keys to navigate): Lab 0 Edge AI Vision, Lab 2 Sensors, Lab 5 Routing, Lab 6 Firebase & RFID
- `Lab*_StudentGuide.html` — rendered student guides (`.md` sources alongside)
- `images/` — figures extracted from the original lab manuals

Hosted on GitHub Pages: https://aioscout.io/tutorial-materials/

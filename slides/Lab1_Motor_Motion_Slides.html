Background · the motor

Voltage in, rotation out

A DC motor is the simplest actuator there is: apply a voltage, it spins; remove it, it stops. More voltage, faster spin.

  • But we can't cleanly give a motor "half a voltage"…
  • …so we give it full voltage half the time
  • The switching is PWM — thousands of on/off cycles per second
  • The ON fraction — the duty cycle — sets the average power, and the speed

Background · the driver

The H-bridge: choosing direction

Reversing a motor means reversing the current through it. An H-bridge is four switches arranged around the motor:

  • S1 + S4 closed → current left-to-right → forward (as drawn)
  • S2 + S3 closed → current reversed → backward
  • All open → stop

Combined  the switch pair sets direction; PWM on the pair sets speed. The driver chip on the car does this for you.

Task 2 · Reading the encoders

The car learns to feel its wheels

Slotted disk + light Counts → distance Counts → speed

In the body analogy, encoders are proprioception — the sense that tells your muscles where your limbs are without looking.

Task 2 · How it works

A disk that chops light into pulses

  • An LED shines through a slotted code disk on the wheel shaft
  • A photosensor sees light — slot — or dark — spoke
  • Each slot that passes = one pulse; count pulses, know the rotation
  • Two channels A and B, offset by 90° — quadrature

Quadrature gifts  direction (which channel rises first) and 4× resolution (count every edge of both channels).

Task 2 · The math

From counts to metres

revolutions = counts / CPR distance = revolutions × wheel circumference speed = distance / time // example: 65 mm wheel (circum ≈ 204 mm), CPR = 360 // 720 counts = 2 revs = 408 mm

Resolution: N slots → 360/N° per count; count both edges → 360/2N; full quadrature → 360/4N.

Concept · feedback

Closing the loop

Open loop: command → motion, no measurement. Drifts. Closed loop: measure the output, compare with the target, correct the difference — every few milliseconds.

Cruise control: without feedback the car slows on every hill; with speed feeding back, power is added the instant speed drops. Same four parts in every control system — the air conditioner (thermostat → controller → compressor → room) and our car (encoder → PID → H-bridge + motor → wheel speed).

The loop  setpoint → error → controller → actuator → process → sensor → back to the start.

Concept · PID

Three terms, one controller

Patented in 1936, still running over 90% of industrial control loops. The lectures explain it with a leaking water tank — hold the level at A while it drains toward B:

P — react to the present

Tap opens in proportion to the gap. With a leak, it settles below target — the steady-state error.

I — remember the past

Error accumulates until the gap is gone. Cost: overshoot and slower settling.

D — anticipate the future

Brakes when the level rises fast — smaller overshoot, faster settle.

Concept · the loop in code

PID, every 10 milliseconds

float Kp = 1.0, Ki = 0.05, Kd = 1.0; float integral = 0, lastError = 0; void controlLoop(float target) { float measured = readSpeed(); // encoder, m/s float error = target - measured; integral += error * dt; // I: accumulate float deriv = (error - lastError) / dt; // D: rate of change lastError = error; float u = Kp*error + Ki*integral + Kd*deriv; motorWrite(constrain(u, 0, MAX_PWM)); // actuator }

Watch for, in order

  • P only — speed settles below target: friction is the leak, the gap is the steady-state error
  • Add I — gap closes, overshoot appears
  • Add D — overshoot shrinks, settle time drops

Task 3  do exactly this on the car, one term at a time, printing measured speed all the while.

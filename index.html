Pedagogy

How the units teach

Hands-on first

Concepts start on the car

Each new concept starts with something observable on the car: drift shows up in the data before it is explained as integration error. The formal theory follows.

Checkpoint-driven

Demos and committed code

Each unit ends at a checkpoint: demonstrate the behaviour to an instructor, commit the code. Progress is measured in working demos, not quizzes.

Compounding build

A single growing system

The PID loop tuned early in the programme still runs at the final project; students maintain the same car and codebase throughout.
